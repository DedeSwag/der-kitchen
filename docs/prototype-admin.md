# 管理端原型设计文档

> 编写日期：2026-05-22  
> 版本：V1.0  
> 适用平台：Web 电脑端（主力）+ 微信小程序内嵌管理页（轻量接单）  
> 目标用户：陈哥（管理员）

---

## 一、平台分工总览

| 平台 | 定位 | 覆盖功能 |
|------|------|----------|
| Web 电脑端 | 完整管理后台 | 菜品管理、分类管理、订单查询、数据统计、权限设置 |
| 小程序管理页 | 厨房移动接单 | 新订单提醒、接单/推进状态、查看备注、取消订单 |

## Part B：小程序管理页（轻量接单）

---

### 四、小程序管理页入口逻辑

**角色判断：** 用户登录后，根据 role 字段判断：
- `role = user` → 进入用户端首页
- `role = admin` → 底部Tab显示"管理"入口，或独立管理首页

**Tab 结构（管理员视角）：**

| Tab | 页面 | 说明 |
|-----|------|------|
| 点菜 | 用户端首页 | 管理员也可体验点菜流程 |
| 接单 | 管理接单工作台 | 管理员核心操作页 |
| 我的 | 个人中心 | 含"去电脑端管理"入口 |

## 七、通知与提醒设计

### 7.1 新订单通知链路

```
用户下单 → 云函数触发 → 微信订阅消息推送（管理员）
                      → 小程序 WebSocket/轮询 → 管理页实时刷新
                      → Web 端 WebSocket → 浏览器通知 + 铃声
```

### 7.2 通知内容模板

**微信订阅消息：**
```
📋 新订单提醒
用餐时段：今日晚餐
菜品：红烧肉×2、番茄蛋汤×1 等3道
下单时间：2026-05-22 17:30
点击查看详情 →
```

**Web 端浏览器通知：**
```
🔔 陈哥厨房 - 新订单
今日晚餐 · 3道菜
红烧肉×2、番茄蛋汤×1...
```

### 7.3 提醒触发规则

| 触发事件 | 通知方式 |
|---------|---------|
| 新订单创建 | 订阅消息 + 小程序内提醒 + Web通知 |
| 用户加菜 | 小程序内提醒 + Web通知 |
| 用户撤销订单 | 小程序内提醒 + Web通知 |
| 待接单超过5分钟 | 小程序内重复提醒 |
