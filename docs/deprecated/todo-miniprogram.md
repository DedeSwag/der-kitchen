# 小程序搭建待办清单

> 技术栈：uni-app + Vue 3 + TypeScript + Pinia  
> 定位：用户端点菜 + 管理员轻量接单（同一小程序，角色区分页面）

---

## 阶段一：工程搭建（0.5天）

- [x] 1.1 使用 HBuilderX 或 CLI 创建 uni-app Vue3 + TS 项目
  ```
  npx degit dcloudio/uni-preset-vue#vite-ts der-kitchen-mp
  ```
- [x] 1.2 安装依赖：
  ```
  pinia
  @dcloudio/uni-ui（uni-app 官方组件库）
  ```
- [x] 1.3 创建项目目录结构：
  ```
  src/
  ├── api/            # 接口请求
  ├── components/     # 公共组件
  ├── composables/    # 组合式函数
  ├── pages/          # 页面
  │   ├── home/       # 首页（点菜）
  │   ├── dish/       # 菜品详情
  │   ├── order/      # 订单相关
  │   ├── mine/       # 个人中心
  │   └── admin/      # 管理员页面
  ├── stores/         # 状态管理
  ├── styles/         # 全局样式
  ├── types/          # TS 类型
  ├── utils/          # 工具函数
  └── static/         # 静态资源（图标等）
  ```
- [x] 1.4 配置 pages.json：
  - tabBar（用户：点菜/订单/我的；管理员：点菜/接单/我的）
  - 页面路由注册
  - 全局样式、导航栏配置
- [x] 1.5 配置 manifest.json（appid、权限声明等）
- [x] 1.6 全局样式变量定义（主色 #FF6B35、辅色、字号、间距）
