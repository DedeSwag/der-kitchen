### 2.1 首页（菜品浏览 + 快速点菜）

**页面路径：** `/pages/home/index`

#### 页面布局（从上到下）

```
├─────────────────────────────┤
│  分类Tab栏（横向滚动）          │
│  [全部] [家常菜] [汤羹] [主食]  │
│  [小吃] [专属私房菜]           │
├─────────────────────────────┤
│  菜品列表区（纵向滚动）          │
│  ┌───────────┬───────────┐  │
│  │ 菜品卡片A  │ 菜品卡片B  │  │
│  │ [图片]    │ [图片]    │  │
│  │ 菜名      │ 菜名      │  │
│  │ ♡ 收藏    │ ♡ 收藏    │  │
│  │ [-] 0 [+] │ [-] 0 [+] │  │
│  └───────────┴───────────┘  │
│  ┌───────────┬───────────┐  │
│  │ 菜品卡片C  │ 菜品卡片D  │  │
│  │ [图片]    │ [图片]    │  │
│  │ [缺货]灰色 │ 菜名      │  │
│  └───────────┴───────────┘  │
├─────────────────────────────┤
│  底部购物车浮层                 │
│  ┌─────────────────────────┐│
│  │ 🛒 已选 3 道菜  [去下单 →] ││
│  └─────────────────────────┘│
├─────────────────────────────┤
│  [点菜]   [订单]   [我的]     │
└─────────────────────────────┘
```

#### 交互说明

| 序号 | 操作 | 响应 |
|------|------|------|
| 1 | 点击分类Tab | 切换展示对应分类菜品，带平滑动画 |
| 2 | 点击菜品卡片图片/菜名 | 进入菜品详情页 |
| 3 | 点击 [+] 按钮 | 菜品数量+1，购物车浮层更新数量 |
| 4 | 点击 [-] 按钮 | 菜品数量-1，为0时隐藏减号 |
| 5 | 点击 ♡ 收藏图标 | 切换收藏状态，收藏时心形变红 |
| 6 | 点击购物车浮层 | 展开已选菜品列表弹窗（可删除/调整数量） |
| 7 | 点击 [去下单] | 跳转确认下单页 |
| 8 | 缺货菜品 | 卡片置灰，[+] 按钮禁用，显示"缺货"标签 |
| 9 | 点击预约时段标签 | 切换当前下单时段，影响后续提交 |

#### 组件规格

**菜品卡片：**
- 尺寸：双列等宽瀑布流，卡片圆角 12rpx
- 图片：正方形，宽度撑满卡片，圆角顶部
- 菜名：最多显示8字，超出省略
- 收藏图标：右上角，24rpx
- 加减按钮：底部居中，高度 56rpx

**购物车浮层：**
- 固定在底部 Tab 栏上方，高度 96rpx
- 左侧购物车图标 + 已选数量角标
- 右侧 [去下单] 按钮，主色调填充

#### 交互说明

| 序号 | 操作 | 响应 |
|------|------|------|
| 1 | 未选择用餐时段点击提交 | toast提示"请选择用餐时段" |
| 2 | 点击 [删] | 从列表移除该菜品，菜品为0时提示"请至少选择一道菜" |

- 选填：口味标签、忌口说明、特殊要求
- 用餐时段默认智能选中（根据当前时间判断最近一餐）

## 四、视觉风格定义

### 4.1 色彩规范

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | #FF6B35 | 暖橙色，食欲感 |
| 辅色 | #2EC4B6 | 清新绿，状态标识 |
| 背景色 | #F8F8F8 | 浅灰背景 |
| 卡片色 | #FFFFFF | 白色卡片 |
| 文字主色 | #333333 | 标题/正文 |
| 文字辅色 | #999999 | 说明文字 |
| 成功色 | #52C41A | 完成状态 |
| 警告色 | #FAAD14 | 待接单状态 |
| 错误色 | #FF4D4F | 取消/缺货 |

### 4.2 字号规范

| 用途 | 字号 | 字重 |
|------|------|------|
| 页面标题 | 36rpx | Bold |
| 卡片标题 | 32rpx | Medium |
| 正文内容 | 28rpx | Regular |
| 辅助说明 | 24rpx | Regular |
| 标签文字 | 22rpx | Regular |

### 4.3 间距规范

| 用途 | 数值 |
|------|------|
| 页面左右边距 | 32rpx |
| 卡片间距 | 24rpx |
| 卡片内边距 | 24rpx |
| 组件间距（大） | 32rpx |
| 组件间距（小） | 16rpx |

### 4.4 设计调性

- **温馨家庭感**：暖色调为主，圆角设计，亲切友好
- **食欲感**：菜品图片突出，橙色主色调激发食欲
- **极简操作**：大按钮、大卡片，操作触区不小于 88rpx
- **趣味性**：适当使用 emoji 和轻松文案

## 六、异常状态处理

| 场景 | 处理方式 |
|------|---------|
| 网络断开 | 顶部红色条提示"网络异常，请检查连接" |
